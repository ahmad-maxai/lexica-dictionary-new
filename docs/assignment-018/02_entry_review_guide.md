# LEXICA — Assignment 018: Entry-by-Entry Review Guide

**Branch:** `feature/assignment-018-fulfulde-human-validation`
**Scope:** Evaluation guide for reviewing all 20 recovery corpus entries independently.

---

## 1. Evaluation Criteria

Reviewers evaluate each entry across 10 independent criteria:
1. Correct headword spelling (Bamako/NERDC Latin standards).
2. Naturalness of the Fulfulde definition (`definitionFf`).
3. Semantic accuracy (does it explain the concept rather than repeat English?).
4. Grammatical correctness.
5. English translation fidelity (`definitionEn`).
6. Naturalness of the Fulfulde example sentence.
7. Accuracy of the English example translation.
8. Dialect and regional appropriateness (`nigerian_adamawa`, etc.).
9. IPA transcription accuracy.
10. Adlam script representation accuracy (`𞤖𞤢𞤳𞥆𞤭𞤤𞤆𞤮`, etc.).

---

## 2. Reviewer Actions

Reviewers are empowered to:
- **Approve:** Confirm the entry is fully correct.
- **Suggest Correction:** Provide a localized spelling, definition, or example improvement.
- **Reject:** Flag fundamental semantic or grammatical errors.
- **Mark Uncertain:** Indicate need for adjudication.
- **Provide Regional Alternatives:** Record dialectal synonyms.
