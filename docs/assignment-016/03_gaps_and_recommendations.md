# LEXICA — Assignment 016: Outstanding Gaps and Recommendations

**Branch:** `feature/assignment-016-fulfulde-lexicography-recovery`

---

## 1. Outstanding Gaps

1. **Corpus Scale:** The recovered native corpus contains 20 core entries. While 100% linguistically verified with genuine native definitions, full dictionary deployment will require scaling to 5,000+ native definitions.
2. **Audio Pronunciations:** Native speaker audio recordings (.mp3/.ogg) for Adamawa Fulfulde headwords are not yet bundled in this recovery release.
3. **Dialect Expansion:** Additional regional variants (Sokoto, Gombe, Maasina, Futa Jallon) need dedicated monolingual synonym mappings.

---

## 2. Recommendations for Future Assignments

1. **Collaborative Native Review:** Partner with university departments (Bayero University Kano CSNL, University of Maiduguri) to review and expand the native definition corpus.
2. **Production UI Integration:** Only after the native corpus reaches 2,000+ verified entries should Fulfulde be enabled in `LanguageLibraryScreen` and production dictionary navigation.
3. **Main Branch Isolation:** Maintain feature branch isolation until comprehensive native speaker review is certified.
